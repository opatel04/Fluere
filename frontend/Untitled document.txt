5 — Interactions & UX rules (exact behavior)
                     * Loading: skeleton lists/cards; spinner on buttons.

                     * Forms: Zod validation + show server/field errors beneath input.

                     * Modals: trap focus, ESC closes, background click closes (confirm destructive requires explicit action).

                     * Notifications: toast system (aria-live="polite").

                     * Optimistic updates: for create/complete tasks (rollback on mock failure).

                     * Drag & drop: keyboard accessible, fallback move menu.

                     * Pagination: page & limit mock; infinite scroll optional.

                     * Filters/URL: search & filters persisted in query string (so devs can share URLs).

                     * Offline: show a persistent banner if navigator is offline (UI-only).

                     * Responsiveness:

                        * <768px mobile: sidebar hidden, sheet for navigation, dialogs full-screen.

                        * 768–1024px tablet: collapsible sidebar.

                        * >1024px desktop: full sidebar + multi-column grid.

________________


6 — Accessibility (must-haves)
                           * All interactive elements keyboard navigable and labeled.

                           * Use semantic HTML (headings, lists).

                           * Modals use role="dialog" and aria-modal.

                           * Tablist for tabs with role="tablist".

                           * Buttons and icon-only controls have aria-label.

                           * Focus visible; respects prefers-reduced-motion.

                           * Color-independent state indicators (icons or badges) — avoid color-only cues.

7 — Minimal API shapes to mock (frontend will use these fixtures now)
Auth
                              * POST /auth/login request { email, password }

                              * Response success:

{ "success": true, "data": { "user": { "id":"u_1","name":"Alex","email":"alex@x.com" } } }


                                 * GET /users/profile → returns same user object.

Clients list
                                    * GET /clients?status=&search=&page=&limit= → returns:

{
  "success": true,
  "data": {
    "clients": [ /* array of client objects below */ ],
    "meta": { "page": 1, "limit": 20, "total": 47 }
  }
}


Client object:
{
  "id":"c_1","name":"Acme Corp","email":"acct@acme.com","company":"Acme",
  "phone":null,"health_score":72,"last_contact":"2025-11-01T12:34:00Z",
  "total_emails":42,"total_tasks":8,"open_tasks":3,"status":"active",
  "created_at":"2024-06-10T09:00:00Z","updated_at":"2025-10-30T09:00:00Z"
}


Client detail
                                       * GET /clients/:id → { success: true, data: { client: {...}, recent_activity: [...], emails_count, tasks_count } }

Tasks
                                          * GET /tasks?client_id=&status=&page=

                                          * POST /tasks req: { client_id, title, description, due_date, priority }

                                          * Task object:

{
  "id":"t_1","title":"Follow up","description":"Call","status":"open",
  "priority":"medium","due_date":"2025-11-07T12:00:00Z","client_id":"c_1",
  "created_at":"2025-11-01T10:00:00Z"
}


Emails
                                             * GET /clients/:id/emails?processed=false&page=

                                             * Email object:

{
  "id":"e_1","from":"john@ex.com","to":["me@tasksnap.com"],
  "subject":"Request for quote","preview":"Hi — can you send pricing for ...",
  "body_html":"<p>Full HTML body</p>","timestamp":"2025-11-03T12:00:00Z","has_tasks":true
}


AI extraction
                                                * POST /ai/extract-manual req { email_id }

                                                * Response:

{ "success": true, "data": { "suggested_tasks": [
  { "id":"s_1","title":"Send pricing","confidence":0.92,"preview":"Prepare quote for product X" }
] } }


Frontend: map suggestions to local POST /tasks calls (mock).
