# TaskSnap - AI Task Organizer Demo

A pure frontend demo of TaskSnap's AI-powered task organization capabilities.

## 🚀 Quick Start

1. **Open the demo:** http://localhost:9000/index.html
2. **Scroll to "Try It Now"** section
3. **Paste messy notes** in the textarea
4. **Click "🤖 Organize with AI"**
5. **Watch tasks get organized!**

## 🎬 Demo Features

- ✅ **Smart Task Extraction** - Identifies tasks from messy text
- ✅ **Priority Assignment** - High/medium/low based on urgency words and dates
- ✅ **Date Recognition** - "tomorrow", "Friday", "end of week" → actual dates
- ✅ **Executive Summaries** - AI-style overviews of task lists
- ✅ **Confidence Scoring** - Shows AI confidence in each task
- ✅ **Calendar Export** - Download .ics files for tasks with dates
- ✅ **Beautiful UI** - Neon design with smooth animations
